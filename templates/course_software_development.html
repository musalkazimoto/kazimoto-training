Complete Software Development Hands-On Lab Manual

For University Students (Computer Science, IT, Computer Engineering, ICT)

Prerequisites: Students have theoretical knowledge of programming concepts

LAB 01 Foundational
Introduction to Software Development
Objective: Students will learn the fundamentals of software development, including the software development lifecycle (SDLC), development methodologies, and essential tools. By the end of this module, students will be able to understand different development methodologies (Waterfall, Agile, Scrum), set up a development environment, use an IDE effectively, write basic programs, and understand coding standards and best practices. Students will also understand the role of a software developer in the industry.
SDLC understanding Development environment setup IDE usage Basic programming Coding standards Problem-solving
LAB 02 Collaboration
Version Control with Git & GitHub
Objective: Students will learn how to use Git for version control and GitHub for collaboration. By the end of this module, students will be able to initialize a Git repository, commit changes, create and merge branches, resolve merge conflicts, use GitHub for collaborative development, implement pull requests and code reviews, and use Git workflows like GitFlow. Students will also understand the importance of version control in team development.
Git commands (init, add, commit, push, pull, branch, merge) GitHub workflows Pull requests Code reviews Conflict resolution GitFlow
LAB 03 Environment
Development Environment Setup
Objective: Students will set up a complete development environment for Python-based web development on Windows using WSL, VS Code, and essential tools. By the end of this module, students will be able to install and configure Windows Subsystem for Linux (WSL), set up Ubuntu on WSL, install and configure Visual Studio Code with essential extensions, set up Python development environment with pyenv/venv, understand the WSL/Windows file system integration, configure Git within WSL, and verify that all tools are working properly. Students will also understand the importance of a consistent development environment for team collaboration.
WSL installation and configuration Ubuntu setup on WSL VS Code installation and extensions Python environment setup (pyenv/venv) Git configuration WSL/Windows integration Development environment verification
LAB 04 Web Development
Frontend Development (HTML, CSS, JavaScript)
Objective: Students will learn how to build responsive and interactive user interfaces using modern frontend technologies. By the end of this module, students will be able to create semantic HTML5 documents, style websites using CSS3 (Flexbox, Grid, animations), implement interactivity using JavaScript (DOM manipulation, event handling, async operations), use responsive design principles, and integrate frontend frameworks like Bootstrap or Tailwind CSS. Students will also understand user experience (UX) and user interface (UI) design principles.
HTML5 semantics CSS3 (Flexbox, Grid, Animations) JavaScript (ES6+) DOM manipulation Event handling Responsive design Bootstrap/Tailwind CSS
LAB 05 Server-Side
Backend Development (Python/Django)
Objective: Students will learn how to build server-side applications using Python and Django. By the end of this module, students will be able to set up a Django project, create models and databases, implement views and URL routing, create templates for dynamic content, handle user authentication and authorization, build REST APIs, and implement security best practices. Students will also understand server-side architecture and MVC pattern.
Python programming Django setup Models and databases Views and URLs Templates Authentication REST APIs Security best practices
LAB 06 Data Storage
Database Design & Management
Objective: Students will learn how to design, implement, and manage databases for software applications. By the end of this module, students will be able to design normalized database schemas, write SQL queries (DDL, DML, DQL), implement relationships (one-to-one, one-to-many, many-to-many), use ORM (Object-Relational Mapping), perform database migrations, optimize query performance, and manage database security. Students will also understand the differences between SQL and NoSQL databases.
Database design Normalization SQL (SELECT, INSERT, UPDATE, DELETE) JOINS ORM (Django ORM/SQLAlchemy) Database migrations Query optimization Database security
LAB 07 Communication
API Development & Integration
Objective: Students will learn how to build and consume APIs for application integration. By the end of this module, students will be able to design RESTful APIs, implement CRUD operations, handle authentication (JWT, OAuth), write API documentation (Swagger/OpenAPI), consume third-party APIs, implement error handling and validation, and test APIs using tools like Postman. Students will also understand API security best practices.
REST API design CRUD operations Authentication (JWT, OAuth) API documentation (Swagger) API consumption Error handling API testing (Postman) Security best practices
LAB 08 Quality
Testing & Quality Assurance
Objective: Students will learn how to ensure software quality through testing and quality assurance practices. By the end of this module, students will be able to write unit tests, integration tests, and end-to-end tests, use testing frameworks (pytest, unittest), implement test-driven development (TDD), perform code reviews, use debugging tools, implement continuous integration, and measure code coverage. Students will also understand the importance of quality assurance in software development.
Unit testing Integration testing End-to-end testing pytest/unittest TDD Code reviews Debugging CI/CD Code coverage
LAB 09 Production
Deployment & DevOps
Objective: Students will learn how to deploy applications to production environments and implement DevOps practices. By the end of this module, students will be able to deploy applications to cloud platforms (Render, AWS, Azure), configure servers and environments, implement CI/CD pipelines, use containerization with Docker, manage environment variables and secrets, implement monitoring and logging, and handle application scaling. Students will also understand DevOps culture and practices.
Cloud deployment (Render/AWS/Azure) Server configuration CI/CD pipelines (GitHub Actions) Docker containerization Environment variables Monitoring and logging Application scaling
LAB 10 Management
Project Management & Agile Methodologies
Objective: Students will learn how to manage software projects using Agile methodologies. By the end of this module, students will be able to implement Scrum and Kanban frameworks, write user stories and acceptance criteria, conduct sprint planning and retrospectives, use project management tools (Jira, Trello, Asana), estimate project timelines and effort, manage stakeholder expectations, and understand project management best practices. Students will also understand the role of a project manager in software development.
Scrum Kanban User stories Sprint planning Retrospectives Project management tools (Jira/Trello) Estimation techniques Stakeholder management
LAB 11 Capstone
Complete Software Development Project (Capstone)
Objective: Students will apply all the skills learned throughout the course to build a complete software application. By the end of this capstone project, students will be able to plan and design a software application from requirements to deployment, implement both frontend and backend components, integrate a database, implement authentication and authorization, write comprehensive tests, deploy the application to production, create project documentation, and present the project to stakeholders. Students will also develop project management, teamwork, and communication skills essential for real-world software development.
Project planning and design Full-stack development Database integration Authentication and authorization Testing Deployment Documentation Presentation Project management and teamwork
