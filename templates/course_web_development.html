Complete Full Stack Web Development Hands-On Lab Manual

For University Students (Computer Science, IT, Computer Engineering, ICT)

Prerequisites: Students have theoretical knowledge of programming concepts

Focus: Practical implementation using WSL environment

LAB 01 Environment
Full Stack Development Environment Setup (WSL)
Objective: Students will set up a complete full stack development environment using WSL (Windows Subsystem for Linux). By the end of this module, students will be able to install and configure WSL 2 with Ubuntu, install and configure Visual Studio Code with WSL extension, install Node.js and npm using nvm (Node Version Manager), install Git and configure SSH keys, install MongoDB and PostgreSQL, set up project structure, and verify all installations with test scripts. Students will also understand the importance of a consistent development environment.
WSL 2 installation and configuration Ubuntu setup VS Code with WSL extension Node.js installation (nvm) npm package management Git configuration MongoDB installation PostgreSQL installation Project structure Environment verification
LAB 02 Frontend
HTML5 & CSS3 Fundamentals
Objective: Students will learn the fundamentals of HTML5 and CSS3 for building web interfaces. By the end of this module, students will be able to create semantic HTML5 documents, use HTML5 elements (header, nav, section, article, footer), apply CSS3 styling (colors, fonts, layouts), use CSS Flexbox and Grid for layouts, implement CSS transitions and animations, create forms and input validation, and build a responsive landing page. Students will also understand the importance of semantic HTML for accessibility and SEO.
HTML5 semantics CSS3 styling Flexbox CSS Grid CSS transitions/animations HTML forms Responsive design Accessibility SEO
LAB 03 Frontend
Responsive Web Design with Tailwind CSS
Objective: Students will learn responsive web design principles and Tailwind CSS framework. By the end of this module, students will be able to implement responsive design using media queries, use Tailwind CSS for rapid development, create mobile-first designs, implement responsive navigation (hamburger menu), use Tailwind grid system and flex utilities, optimize images for responsive design, and build a fully responsive website. Students will also understand the importance of mobile-first design.
Responsive design principles Media queries Tailwind CSS Mobile-first design Responsive navigation CSS grid systems Image optimization Mobile-first design
LAB 04 Frontend
JavaScript Fundamentals & DOM Manipulation
Objective: Students will learn JavaScript fundamentals and DOM manipulation. By the end of this module, students will be able to write JavaScript code (variables, functions, loops, conditionals), manipulate the DOM (selecting elements, changing content, adding events), handle user events (click, hover, submit), implement form validation, create dynamic content, use the browser console for debugging, and build interactive web applications. Students will also understand the role of JavaScript in modern web development.
JavaScript fundamentals (variables, functions, loops, conditionals) DOM manipulation Event handling Form validation Dynamic content creation Browser console debugging Interactive web applications
LAB 05 Frontend
Modern JavaScript (ES6+) & Async Programming
Objective: Students will learn modern JavaScript features and asynchronous programming. By the end of this module, students will be able to use ES6+ features (arrow functions, template literals, destructuring, spread/rest operators), implement classes and modules, use Promises and async/await for asynchronous operations, make API calls using fetch and axios, handle errors in asynchronous code, use map, filter, and reduce for array manipulation, and build a modern JavaScript application. Students will also understand the importance of asynchronous programming.
ES6+ features (arrow functions, template literals, destructuring) Classes and modules Promises and async/await API calls (fetch/axios) Error handling Array methods (map, filter, reduce) Modern JavaScript applications
LAB 06 Frontend
Frontend Framework: React.js (Practical)
Objective: Students will learn React.js for building modern user interfaces. By the end of this module, students will be able to set up a React project using Create React App or Vite, create functional and class components, use JSX syntax, manage state using useState and useReducer, manage side effects using useEffect, implement routing with React Router, handle forms and user input, use props and component composition, and build a complete React application. Students will also understand the component-based architecture of React.
Create React App/Vite setup Functional components JSX syntax useState and useReducer useEffect for side effects React Router Form handling Props and component composition React application development Component-based architecture
LAB 07 Backend
Backend Development with Node.js & Express
Objective: Students will learn backend development using Node.js and Express. By the end of this module, students will be able to set up a Node.js server with Express, create routes and handle HTTP methods (GET, POST, PUT, DELETE), implement middleware for request processing, handle request parameters and body data, implement error handling and logging, use environment variables for configuration, structure a Node.js application with MVC pattern, and build a RESTful API. Students will also understand the role of backend in full stack development.
Node.js server setup Express routes and HTTP methods Middleware Request handling Error handling and logging Environment variables MVC pattern RESTful API development
LAB 08 Backend
RESTful API Development
Objective: Students will learn RESTful API development and best practices. By the end of this module, students will be able to design RESTful API endpoints, implement CRUD operations, handle request validation and sanitization, implement pagination, sorting, and filtering, write API documentation using Swagger/OpenAPI, test APIs using Postman, implement rate limiting and security headers, and build a complete RESTful API. Students will also understand the principles of REST architecture.
RESTful API design CRUD operations Request validation and sanitization Pagination, sorting, and filtering Swagger/OpenAPI documentation Postman API testing Rate limiting and security headers REST architecture principles
LAB 09 Database
Database Integration (PostgreSQL/MongoDB)
Objective: Students will learn database integration for full stack applications. By the end of this module, students will be able to set up MongoDB with Mongoose ODM, set up PostgreSQL with Sequelize ORM, create schemas and models, perform CRUD operations, implement relationships and data validation, use query builders and aggregation, handle database migrations and seeding, optimize database queries with indexes, and build a full stack application with database integration. Students will also understand the differences between SQL and NoSQL databases.
MongoDB setup and Mongoose ODM PostgreSQL setup and Sequelize ORM Schemas and models CRUD operations Relationships and data validation Query builders and aggregation Database migrations and seeding Query optimization with indexes Full stack database integration
LAB 10 Security
Authentication & Authorization (JWT)
Objective: Students will learn authentication and authorization for full stack applications. By the end of this module, students will be able to implement JWT (JSON Web Token) authentication, implement session-based authentication with cookies, implement role-based access control (RBAC), implement password hashing and salting (bcrypt), protect routes and APIs, implement social authentication (OAuth), implement refresh tokens and password reset, handle authentication errors, and build a secure authentication system. Students will also understand the importance of security in web applications.
JWT authentication Session-based authentication with cookies Role-based access control (RBAC) Password hashing and salting (bcrypt) Route and API protection Social authentication (OAuth) Refresh tokens and password reset Authentication error handling Secure authentication systems
LAB 11 Frontend
State Management (Redux/Context API)
Objective: Students will learn state management for complex React applications. By the end of this module, students will be able to implement Redux for global state management, use Redux Toolkit for simplified Redux, implement Context API for component-level state, manage async actions with Redux Thunk, use React Query for server state management, implement Redux DevTools for debugging, handle complex state updates, and build a React application with efficient state management. Students will also understand the importance of state management in large applications.
Redux global state management Redux Toolkit Context API Redux Thunk for async actions React Query for server state Redux DevTools debugging Complex state updates State management in React
LAB 12 Deployment
Deployment & DevOps (Render/AWS)
Objective: Students will learn deployment and DevOps practices for full stack applications. By the end of this module, students will be able to deploy applications to Render, AWS, or similar platforms, configure environment variables and secrets, implement CI/CD pipelines with GitHub Actions, use containerization with Docker, manage logs and monitoring, implement SSL/TLS for secure connections, scale applications for traffic, and create deployment documentation. Students will also understand the importance of DevOps in modern development.
Cloud deployment (Render/AWS) Environment variables and secrets CI/CD pipelines (GitHub Actions) Docker containerization Logs and monitoring SSL/TLS configuration Application scaling Deployment documentation DevOps practices
LAB 13 Capstone
Full Stack Application Development
Objective: Students will apply all the skills learned throughout the course to build a complete full stack application. By the end of this capstone project, students will be able to design and architect a full stack application, implement frontend using React, implement backend using Node.js/Express, integrate a database (MongoDB/PostgreSQL), implement authentication and authorization, build RESTful APIs, write comprehensive tests, deploy the application to production, create project documentation, and present the project to stakeholders. Students will also develop project management, teamwork, and communication skills essential for real-world full stack development.
Application architecture and design Full stack implementation Database integration Authentication and authorization RESTful API development Testing Deployment Documentation and presentation Project management and teamwork
