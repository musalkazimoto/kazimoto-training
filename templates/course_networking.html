Complete Networking Hands-On Lab Manual

For University Students (Computer Science, IT, Computer Engineering, ICT and Telecommunication Eng)

Prerequisites: Students have theoretical knowledge of networking concepts

LAB 01 Foundational
Network Cabling & Termination
Objective: Students will learn the fundamental skills of creating and terminating network cables. By the end of this lab, students will be able to identify different cable types, properly strip and prepare cables, terminate RJ45 connectors using both T568A and T568B standards, create straight-through, crossover, and rollover cables, test cables using a cable tester, and troubleshoot common cabling issues. Students will also understand the importance of proper cable installation techniques including maintaining bend radius and using appropriate cable management.
Cable stripping RJ45 termination T568A/T568B standards Straight-through/Crossover/Rollover Cable testing Troubleshooting
LAB 02 Infrastructure
Ethernet Cable Jointing & Repair
Objective: Students will learn how to repair damaged Ethernet cables and create cable joints for network installations. By the end of this lab, students will be able to identify different types of cable damage, properly prepare cable ends for jointing, use RJ45 couplers for indoor repairs, use gel-filled connectors for waterproof outdoor joints, apply heat shrink splices for permanent repairs, test the integrity of cable joints using cable testers, and properly document cable repairs for future reference. Students will also understand the importance of maintaining cable infrastructure and the cost-effectiveness of proper cable repair techniques.
Cable damage identification RJ45 coupler jointing Gel-filled connectors Heat shrink splicing Cable testing Repair documentation
LAB 03 Infrastructure
Cable Trunking & Raceway Installation
Objective: Students will learn how to install cable trunking, raceways, and cable trays for organized and professional network cable management. By the end of this lab, students will be able to select appropriate trunking types for different applications, measure and cut trunking accurately, install surface-mounted trunking on walls, install underfloor trunking, lay cables neatly within trunking systems, install raceways and conduits, apply proper cable segregation rules (power vs data), install cable ladders and trays in server rooms, and implement proper cable management techniques. Students will also understand the importance of trunking for cable protection, organization, aesthetics, and future scalability.
Trunking selection Trunking cutting/installation Surface/underfloor trunking Cable segregation Raceway installation Cable ladder/tray Fire stopping
LAB 04 Infrastructure
Face Plate & Keystone Installation
Objective: Students will learn the proper techniques for installing wall face plates and terminating keystone jacks. By the end of this lab, students will be able to identify different types of face plates and keystone jacks, properly terminate keystone jacks using the T568B wiring standard, install face plates on wall boxes, apply proper labeling conventions, and test their installations using cable testers. Students will also understand the importance of color coding and documentation in professional network installations.
Keystone jack termination Punch down tool usage Face plate mounting Color coding Labeling conventions Cable testing
LAB 05 Infrastructure
Patch Panel & Cable Management
Objective: Students will learn how to properly install and terminate patch panels in a network rack environment. By the end of this lab, students will be able to mount a patch panel in a rack, terminate cables to the patch panel using the T568B standard, organize cables using proper cable management techniques, label all connections according to professional standards, and test the completed installation. Students will also understand the importance of neat cable organization for maintainability and troubleshooting in enterprise networks.
Patch panel mounting Cable termination 110 punch down tool Cable management Velcro bundling Labeling Cable testing
LAB 06 Infrastructure
Cabinet/Rack Installation
Objective: Students will learn the complete process of installing a network cabinet or server rack. By the end of this lab, students will be able to assemble a server rack, properly position and level it in the designated location, install equipment in the rack using proper rack units and spacing, manage power distribution, ensure proper grounding, and organize cables for optimal airflow and accessibility. Students will also understand the importance of proper rack placement for cooling, maintenance, and scalability in network infrastructure.
Rack assembly and leveling Equipment mounting Rack unit spacing Power distribution Grounding Cable management Cooling and airflow planning
LAB 07 Switching
Switch Installation & VLAN Configuration
Objective: Students will learn how to install and configure network switches in a structured network environment. By the end of this lab, students will be able to perform initial switch configuration including hostname, passwords, and management IP, create and configure VLANs for network segmentation, configure trunk ports for inter-switch connectivity, implement inter-VLAN routing using router-on-a-stick or layer 3 switching, configure DHCP services, and verify network connectivity across all VLANs. Students will also understand the security benefits of network segmentation and VLAN implementation.
Switch initial configuration VLAN creation and assignment Trunk configuration Inter-VLAN routing DHCP configuration Network verification and testing
LAB 08 Routing
Router Installation & Configuration
Objective: Students will learn how to install and configure routers to enable network connectivity between different networks. By the end of this lab, students will be able to perform initial router configuration including hostname, passwords, and interface IP addressing, configure static routes for fixed network paths, implement dynamic routing protocols (RIP and OSPF) for automatic route learning, configure access control lists (ACLs) for traffic filtering, implement NAT for internet connectivity, and verify routing functionality through ping and traceroute tests. Students will also understand the differences between static and dynamic routing and when to use each approach.
Router initial configuration Static routing Dynamic routing (RIP/OSPF) Access Control Lists (ACL) NAT configuration Route verification and troubleshooting
LAB 09 Security
Firewall Installation & Configuration
Objective: Students will learn how to install and configure a firewall to secure a network environment. By the end of this lab, students will be able to install pfSense/OPNsense firewall software, configure network interfaces for WAN, LAN, and DMZ zones, implement firewall rules to control traffic flow between zones, configure NAT and port forwarding for public services, set up site-to-site VPN connectivity, implement traffic shaping for bandwidth management, and monitor firewall logs for security events. Students will also understand the importance of defense-in-depth and network security best practices.
Firewall installation Interface configuration Firewall rule creation NAT and port forwarding VPN configuration Traffic shaping Security log monitoring
LAB 10 Capstone
Complete Network Installation (Capstone)
Objective: Students will apply all the skills learned throughout the course to design, install, and configure a complete functional network. By the end of this capstone lab, students will be able to design a network addressing scheme, install face plates and terminate keystone jacks, mount a patch panel and organize cable management, install switches and configure VLANs, install routers and configure routing, install a firewall and implement security policies, test the entire network for functionality, and create complete network documentation including diagrams and configuration files. Students will also develop project management skills, teamwork abilities, and professional documentation practices essential for real-world network deployment.
Network design Complete physical installation Device configuration Inter-VLAN routing DHCP and DNS services Network testing and verification Documentation and reporting Project management and teamwork
