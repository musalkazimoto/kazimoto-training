Complete Linux Server Administration Hands-On Lab Manual

For University Students (Computer Science, IT, Computer Engineering, ICT)

Prerequisites: Students have theoretical knowledge of Linux operating systems and basic command-line usage

Focus: Practical implementation and hands-on server administration

LAB 01 Environment
Linux Server Environment Setup (WSL/VM)
Objective: Students will set up a complete Linux server environment using WSL (Windows Subsystem for Linux) or a virtual machine. By the end of this module, students will be able to install and configure Ubuntu Server on WSL/VM, set up SSH access for remote administration, install essential server tools, configure basic system settings, understand the Linux file system hierarchy, and verify the server environment. Students will also understand the importance of a secure and consistent server environment.
WSL/VM installation Ubuntu Server setup SSH configuration Essential server tools System settings File system hierarchy Environment verification
LAB 02 File System
Linux File System & Permission Management
Objective: Students will learn Linux file system structure and permission management. By the end of this module, students will be able to navigate the Linux file system, understand the directory structure, manage file permissions (chmod, chown, chgrp), set up file ownership, create and manage files and directories, use symbolic and hard links, and configure disk quotas. Students will also understand the importance of proper permission management for server security.
File system navigation Directory structure File permissions (chmod, chown, chgrp) File ownership Symbolic and hard links Disk quotas Permission management
LAB 03 User Management
User & Group Administration
Objective: Students will learn user and group administration on Linux servers. By the end of this module, students will be able to create and manage user accounts, create and manage groups, set password policies, configure user environments, use sudo for privilege escalation, manage user profiles, and enforce password aging policies. Students will also understand the importance of proper user management for server security.
User creation and management Group creation and management Password policies Sudo configuration User environments Password aging User profiles
LAB 04 Package Management
Package Management (APT/YUM)
Objective: Students will learn package management on Linux servers using APT (Debian/Ubuntu) and YUM (RHEL/CentOS). By the end of this module, students will be able to install, update, and remove software packages, manage repositories, use package dependencies, compile software from source, and manage package updates. Students will also understand the importance of regular software updates for server security.
APT package management YUM package management Repository management Package installation/update/removal Dependency resolution Source compilation Software updates
LAB 05 System Management
Process Management & System Monitoring
Objective: Students will learn process management and system monitoring on Linux servers. By the end of this module, students will be able to view and manage running processes, use process monitoring tools (top, htop, ps), manage system services, set process priorities, monitor system resources (CPU, memory, disk, network), and troubleshoot performance issues. Students will also understand the importance of system monitoring for server health.
Process viewing (ps, top, htop) Process management (kill, nice, renice) Service management (systemctl) System monitoring (htop, iostat, netstat) Resource monitoring Performance troubleshooting
LAB 06 Networking
Network Configuration & Services
Objective: Students will learn network configuration and services on Linux servers. By the end of this module, students will be able to configure network interfaces, set static IP addresses, configure DNS settings, manage network services, troubleshoot network connectivity, and implement network security measures. Students will also understand the importance of proper network configuration for server accessibility.
Network interface configuration Static IP setup DNS configuration Network service management Network troubleshooting Network security
LAB 07 Networking & Security
SSH, DNS, DHCP & Syslog Server Configuration
Objective: Students will learn to configure and manage essential network services including SSH, DNS, DHCP, and Syslog servers on Linux. By the end of this module, students will be able to configure SSH server with key-based authentication and security hardening, set up DNS server (Bind9) for domain name resolution, configure DHCP server (isc-dhcp-server) for automatic IP assignment, set up Syslog server (rsyslog) for centralized logging, implement security best practices for all services, and troubleshoot common issues. Students will also understand the importance of these core network services in a server environment.
SSH server configuration and security hardening DNS server setup (Bind9) DHCP server configuration (isc-dhcp-server) Syslog server setup (rsyslog) Service integration and troubleshooting Network service security Centralized logging
LAB 08 Web Server
Web Server (Apache/Nginx) Configuration
Objective: Students will learn web server configuration using Apache or Nginx. By the end of this module, students will be able to install and configure Apache/Nginx, set up virtual hosts, configure SSL/TLS certificates, implement URL rewriting, configure load balancing, and secure the web server. Students will also understand the importance of web server security and performance tuning.
Apache installation and configuration Nginx installation and configuration Virtual hosts SSL/TLS configuration URL rewriting Load balancing Web server security
LAB 09 Database
Database Server (MySQL/PostgreSQL) Setup
Objective: Students will learn database server setup and management using MySQL or PostgreSQL. By the end of this module, students will be able to install and configure MySQL/PostgreSQL, create and manage databases, create users and manage privileges, perform backups and restores, optimize database performance, and secure the database server. Students will also understand the importance of database security and regular backups.
MySQL/PostgreSQL installation Database creation and management User management and privileges Backups and restores Performance optimization Database security
LAB 10 Security
Firewall Configuration (UFW/iptables)
Objective: Students will learn firewall configuration using UFW and iptables. By the end of this module, students will be able to configure UFW for basic firewall rules, implement advanced firewall rules with iptables, set up NAT and port forwarding, block malicious IP addresses, and monitor firewall logs. Students will also understand the importance of firewall protection for server security.
UFW configuration iptables rules NAT and port forwarding IP blocking Firewall logging Server security
LAB 11 Backup
Backup & Recovery Strategies
Objective: Students will learn backup and recovery strategies for Linux servers. By the end of this module, students will be able to implement file-level backups with rsync, implement system backups with tar, schedule automated backups with cron, manage backup rotation, perform disaster recovery, and test backup integrity. Students will also understand the importance of regular backups for data protection.
rsync backups tar backups Cron scheduling Backup rotation Disaster recovery Backup integrity testing
LAB 12 Automation
Server Automation with Bash Scripting
Objective: Students will learn server automation using Bash scripting. By the end of this module, students will be able to write Bash scripts for server administration, create automated deployment scripts, implement system monitoring scripts, manage backups with scripts, and automate routine maintenance tasks. Students will also understand the importance of automation for efficient server management.
Bash scripting Automated deployments System monitoring scripts Backup automation Maintenance automation
LAB 13 Capstone
Complete Server Deployment
Objective: Students will apply all the skills learned throughout the course to deploy a complete Linux server. By the end of this capstone project, students will be able to plan and deploy a production-ready Linux server, configure web and database services, implement security measures, set up monitoring and logging, create backup strategies, automate routine tasks, and document the deployment process. Students will also develop project management, teamwork, and documentation skills essential for real-world server administration.
Server planning and deployment Web and database services Security implementation Monitoring and logging Backup strategies Automation Documentation and reporting Project management and teamwork
