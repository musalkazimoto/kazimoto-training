Complete Artificial Intelligence Hands-On Lab Manual

For University Students (Computer Science, IT, Computer Engineering, ICT)

Prerequisites: Students have theoretical knowledge of AI/ML concepts

Focus: Practical implementation and data analysis

LAB 01 Environment
Python for Data Analysis & AI
Objective: Students will set up a complete Python environment for data analysis and AI with all essential libraries. By the end of this module, students will be able to install and configure Anaconda/Jupyter Notebook, install essential data analysis libraries (NumPy, Pandas, Matplotlib, Seaborn, Scikit-learn, TensorFlow), set up virtual environments, understand the Python data science ecosystem, and verify all installations with a test script. Students will also understand the workflow of a data science project.
Anaconda/Jupyter setup NumPy Pandas Matplotlib Seaborn Scikit-learn TensorFlow Virtual environments
LAB 02 Data Collection
Data Collection & Loading Techniques
Objective: Students will learn various methods to collect and load data from different sources. By the end of this module, students will be able to load data from CSV, Excel, and JSON files, connect to and query SQL databases, scrape data from websites using BeautifulSoup, fetch data from APIs (RESTful APIs), handle different data formats, deal with large datasets efficiently, and merge/concatenate data from multiple sources. Students will also understand the importance of data collection in the AI pipeline.
CSV/Excel/JSON loading SQL database connection Web scraping (BeautifulSoup) API integration Large dataset handling Data merging
LAB 03 Data Analysis
Exploratory Data Analysis (EDA) & Visualization
Objective: Students will perform comprehensive EDA to understand data patterns, distributions, and relationships. By the end of this module, students will be able to generate summary statistics for data, identify data types and missing values, create various visualizations (histograms, box plots, scatter plots, heatmaps), understand correlations between variables, identify outliers and anomalies, perform univariate, bivariate, and multivariate analysis, and effectively communicate insights through visualizations. Students will also understand the role of EDA in the AI workflow.
Summary statistics Data profiling Missing value analysis Data visualization (histograms, box plots, scatter plots, heatmaps) Correlation analysis Outlier detection Univariate/Bivariate/Multivariate analysis
LAB 04 Data Preparation
Data Preprocessing & Feature Engineering
Objective: Students will learn how to prepare data for machine learning models through preprocessing and feature engineering. By the end of this module, students will be able to handle missing values using various imputation techniques, encode categorical variables (One-Hot Encoding, Label Encoding), scale and normalize features (StandardScaler, MinMaxScaler), handle outliers using IQR and Z-score methods, create new features through feature engineering, perform feature selection for model improvement, split data for training and testing, and implement data pipelines. Students will also understand the impact of preprocessing on model performance.
Missing value imputation Categorical encoding (One-Hot, Label) Feature scaling (StandardScaler, MinMaxScaler) Outlier handling (IQR, Z-score) Feature engineering Feature selection Train/test split Data pipelines
LAB 05 Statistics
Statistical Analysis for Data Science
Objective: Students will learn essential statistical concepts and techniques for data analysis. By the end of this module, students will be able to perform hypothesis testing (t-test, chi-square), conduct ANOVA for comparing multiple groups, calculate correlation coefficients (Pearson, Spearman), perform regression analysis, conduct time series decomposition, test for normality and homogeneity, perform A/B testing analysis, and create confidence intervals. Students will also understand the role of statistics in data-driven decision making.
Hypothesis testing (t-test, chi-square) ANOVA Correlation (Pearson, Spearman) Regression analysis Time series decomposition Normality testing (Shapiro-Wilk) Homogeneity testing (Levene's) A/B testing Confidence intervals
LAB 06 Regression
Regression Analysis (Predictive Modeling)
Objective: Students will implement and evaluate regression models for predictive analysis. By the end of this module, students will be able to implement linear regression for prediction, implement polynomial regression for non-linear relationships, implement Ridge and Lasso regression for regularization, implement logistic regression for binary classification, evaluate regression models using appropriate metrics (MSE, RMSE, MAE, R²), perform feature selection using L1 regularization, understand the assumptions of linear regression, and apply regression to real-world datasets. Students will also understand the limitations and assumptions of regression models.
Linear regression Polynomial regression Ridge and Lasso regression Logistic regression Model evaluation (MSE, RMSE, MAE, R²) Feature selection with L1 regularization Regression assumptions Real-world regression applications
LAB 07 Classification
Classification Algorithms (Practical)
Objective: Students will implement and evaluate classification algorithms for predictive modeling. By the end of this module, students will be able to implement classification algorithms (KNN, Decision Trees, Random Forest, SVM, Naive Bayes), evaluate classification models using appropriate metrics (Accuracy, Precision, Recall, F1-Score, ROC-AUC), handle imbalanced datasets, perform hyperparameter tuning using GridSearchCV, understand ensemble methods for improved performance, and interpret model predictions using confusion matrix and classification report.
K-Nearest Neighbors (KNN) Decision Trees Random Forest Support Vector Machines (SVM) Naive Bayes Model evaluation (Accuracy, Precision, Recall, F1-Score, ROC-AUC) Imbalanced data handling Hyperparameter tuning (GridSearchCV) Ensemble methods Confusion matrix
LAB 08 Clustering
Clustering & Segmentation
Objective: Students will implement clustering algorithms for customer segmentation and pattern discovery. By the end of this module, students will be able to implement K-Means clustering for segmentation, implement Hierarchical clustering for hierarchy discovery, implement DBSCAN for density-based clustering, determine optimal number of clusters using Elbow Method and Silhouette Score, visualize clustering results, interpret cluster characteristics, and apply clustering to real-world problems (customer segmentation, image compression, anomaly detection). Students will also understand the strengths and weaknesses of different clustering algorithms.
K-Means clustering Hierarchical clustering DBSCAN Elbow Method Silhouette Score Cluster visualization Cluster interpretation Customer segmentation Anomaly detection
LAB 09 Feature Engineering
Dimensionality Reduction & Feature Selection
Objective: Students will learn techniques to reduce data dimensionality and select relevant features for model improvement. By the end of this module, students will be able to implement Principal Component Analysis (PCA) for dimensionality reduction, implement t-SNE for data visualization, implement Linear Discriminant Analysis (LDA) for supervised feature extraction, perform feature selection using various techniques (filter, wrapper, embedded methods), interpret and visualize reduced dimensions, and understand the trade-offs between dimensionality reduction and information loss. Students will also understand the computational benefits of dimensionality reduction.
Principal Component Analysis (PCA) t-SNE Linear Discriminant Analysis (LDA) Feature selection (filter, wrapper, embedded) Dimensionality reduction visualization Information loss trade-off Computational efficiency
LAB 10 Time Series
Time Series Analysis & Forecasting
Objective: Students will learn techniques for analyzing and forecasting time series data. By the end of this module, students will be able to decompose time series into trend, seasonality, and residual components, implement ARIMA models for forecasting, implement SARIMA for seasonal data, use Prophet for time series forecasting, create lag features for regression-based forecasting, evaluate forecasting models using appropriate metrics (MAE, RMSE, MAPE), and visualize time series patterns. Students will also understand the challenges of time series forecasting.
Time series decomposition ARIMA models SARIMA models Prophet forecasting Lag feature creation Forecasting metrics (MAE, RMSE, MAPE) Time series visualization Trend and seasonality detection
LAB 11 Deep Learning
Deep Learning with TensorFlow/Keras (Practical)
Objective: Students will implement deep learning models using TensorFlow and Keras for real-world problems. By the end of this module, students will be able to build neural networks using Keras Sequential API, create custom architectures with Functional API, implement transfer learning for image classification, use pre-trained models (VGG16, ResNet50), train models with data augmentation, implement regularization techniques (Dropout, BatchNormalization), save and load models, and evaluate model performance. Students will also understand the practical considerations of training deep learning models.
TensorFlow/Keras Sequential API Functional API Transfer learning Pre-trained models Data augmentation Dropout and BatchNormalization Model saving and loading Model evaluation
LAB 12 NLP
NLP for Data Analysis
Objective: Students will implement NLP techniques for text data analysis. By the end of this module, students will be able to preprocess text data (tokenization, stopword removal, lemmatization), convert text to numerical features (Bag-of-Words, TF-IDF, Word Embeddings), build text classification models (sentiment analysis, spam detection), perform topic modeling (LDA), use transformers for text analysis (BERT, RoBERTa), visualize text data with word clouds, and extract insights from text data. Students will also understand the applications of NLP in business and social media analysis.
Text preprocessing (tokenization, stopword removal, lemmatization) Bag-of-Words TF-IDF Word Embeddings (Word2Vec, GloVe) Text classification Sentiment analysis Topic modeling (LDA) Transformers (BERT, RoBERTa) Word cloud visualization Text data insights extraction
LAB 13 Capstone
End-to-End Data Analysis & AI Project
Objective: Students will apply all the skills learned throughout the course to complete an end-to-end data analysis and AI project. By the end of this capstone project, students will be able to define a problem and collect relevant data, perform comprehensive EDA and preprocessing, build and evaluate AI/ML models, deploy the solution as a web API or application, create interactive dashboards, document the project thoroughly, and present findings to stakeholders. Students will also develop project management, teamwork, and communication skills essential for real-world AI development.
Problem definition and project planning Data collection and preparation EDA and visualization Feature engineering Model building and evaluation Model deployment Dashboard creation Documentation and presentation Project management and teamwork
