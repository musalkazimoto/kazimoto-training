Complete Cybersecurity Hands-On Lab Manual

For University Students (Computer Science, IT, Computer Engineering, ICT)

Prerequisites: Students have theoretical knowledge of networking and security concepts

Focus: Practical implementation and hands-on security training

LAB 01 Environment
Cybersecurity Lab Setup (Kali Linux & Target VMs)
Objective: Students will set up a complete cybersecurity lab environment for ethical hacking and security testing. By the end of this module, students will be able to install and configure VirtualBox/VMware, install Kali Linux as the attacker machine, install Metasploitable 2 as a vulnerable target, install Windows 10 as a target, configure Host-Only and NAT networking, understand the lab network topology, and verify connectivity between all VMs. Students will also understand the importance of an isolated lab environment.
VirtualBox/VMware setup Kali Linux installation Metasploitable 2 setup Windows target setup Host-Only network configuration NAT configuration Lab network topology VM connectivity verification
LAB 02 Reconnaissance
Reconnaissance & OSINT
Objective: Students will learn passive and active reconnaissance techniques for information gathering. By the end of this module, students will be able to perform passive reconnaissance using OSINT techniques (Google dorking, WHOIS, DNS enumeration), perform active reconnaissance using scanning tools, gather information about targets without detection, use tools like theHarvester, Maltego, and Recon-ng, understand the importance of footprinting in ethical hacking, and document findings professionally. Students will also understand the legal implications of reconnaissance.
OSINT techniques Google dorking WHOIS lookup DNS enumeration theHarvester Maltego Recon-ng Footprinting Documentation
LAB 03 Scanning
Network Scanning & Enumeration
Objective: Students will learn advanced network scanning and enumeration techniques. By the end of this module, students will be able to perform port scanning using Nmap (SYN, TCP, UDP), identify open ports and services, perform OS and version detection, enumerate services (SMB, FTP, SSH, HTTP), use Nmap scripting engine (NSE), perform vulnerability detection with Nmap, and create comprehensive scan reports. Students will also understand the importance of enumeration in penetration testing.
Nmap (SYN, TCP, UDP scans) Port scanning Service enumeration OS detection Version detection NSE scripts Vulnerability detection Scan reporting
LAB 04 Assessment
Vulnerability Assessment
Objective: Students will learn how to identify, assess, and prioritize vulnerabilities in systems and networks. By the end of this module, students will be able to use Nessus/OpenVAS for vulnerability scanning, interpret vulnerability scan results, prioritize vulnerabilities based on CVSS scores, identify common misconfigurations, use Nikto for web server scanning, use OWASP ZAP for web application scanning, create vulnerability assessment reports, and understand the vulnerability management lifecycle. Students will also understand the difference between vulnerability assessment and penetration testing.
Nessus/OpenVAS vulnerability scanning CVSS scoring Vulnerability prioritization Nikto web server scanning OWASP ZAP web application scanning Misconfiguration identification Vulnerability assessment reports Vulnerability management lifecycle
LAB 05 Web Security
Web Application Security (OWASP Top 10)
Objective: Students will learn to identify and exploit common web application vulnerabilities. By the end of this module, students will be able to perform SQL Injection attacks (Error-based, Union-based, Blind), conduct Cross-Site Scripting (XSS) attacks (Reflected, Stored, DOM), perform Cross-Site Request Forgery (CSRF) attacks, exploit File Inclusion vulnerabilities (LFI/RFI), use Burp Suite for web penetration testing, use SQLmap for automated SQL injection, implement OWASP Top 10 security controls, and create web application security reports. Students will also understand the importance of secure coding practices.
SQL Injection (Error-based, Union-based, Blind) Cross-Site Scripting (XSS - Reflected, Stored, DOM) CSRF attacks File Inclusion (LFI/RFI) Burp Suite SQLmap OWASP Top 10 Secure coding practices Web app security reports
LAB 06 Exploitation
Exploitation with Metasploit
Objective: Students will learn to use the Metasploit Framework for penetration testing and exploitation. By the end of this module, students will be able to navigate the Metasploit Framework, search for and use exploits, set payloads (Reverse Shell, Bind Shell, Meterpreter), exploit common vulnerabilities (vsftpd, Samba, UnrealIRCd), perform privilege escalation, use Meterpreter for post-exploitation, maintain persistence, and document exploitation findings. Students will also understand the ethical considerations of exploitation.
Metasploit Framework Exploit search and selection Payload configuration (Reverse Shell, Bind Shell, Meterpreter) vsftpd exploitation Samba exploitation UnrealIRCd exploitation Privilege escalation Meterpreter post-exploitation Persistence Documentation
LAB 07 Authentication
Password Cracking & Authentication Attacks
Objective: Students will learn techniques for password cracking and authentication attacks. By the end of this module, students will be able to perform dictionary and brute-force attacks using tools like John the Ripper and Hashcat, capture password hashes using Responder, perform password spraying attacks, use Hydra for online brute-force attacks, crack Windows and Linux password hashes, understand password policies and best practices, implement multi-factor authentication (MFA), and create password security reports. Students will also understand the importance of strong password policies.
John the Ripper Hashcat Dictionary attacks Brute-force attacks Responder (hash capture) Password spraying Hydra (online brute-force) Windows/Linux hash cracking Password policies Multi-factor authentication (MFA)
LAB 08 Wireless
Wireless Network Security
Objective: Students will learn wireless network security concepts and attack techniques. By the end of this module, students will be able to put wireless adapters in monitor mode, perform Wi-Fi reconnaissance (airodump-ng), capture WPA handshake (airodump-ng), perform deauthentication attacks (aireplay-ng), crack WPA passwords (aircrack-ng), perform Evil Twin attacks (airbase-ng), implement Wi-Fi security best practices (WPA3, Enterprise), and create wireless security assessment reports. Students will also understand the evolution of Wi-Fi security (WEP → WPA → WPA2 → WPA3).
Monitor mode airodump-ng (Wi-Fi reconnaissance) Handshake capture Deauthentication attacks (aireplay-ng) WPA password cracking (aircrack-ng) Evil Twin attacks (airbase-ng) Wi-Fi security best practices WPA2/WPA3 Wireless security assessment reports
LAB 09 Defense
Network Defense & Firewall Configuration
Objective: Students will learn to implement network defense mechanisms and configure firewalls. By the end of this module, students will be able to implement defense-in-depth strategies, configure firewalls (iptables/ufw on Linux, Windows Firewall), create firewall rules for inbound and outbound traffic, implement Network Address Translation (NAT), configure Intrusion Prevention Systems (IPS), implement network segmentation with VLANs, use network monitoring tools, and create security incident reports. Students will also understand the importance of proactive defense.
Defense-in-depth Firewall configuration (iptables, ufw, Windows Firewall) Firewall rule creation Network Address Translation (NAT) Intrusion Prevention Systems (IPS) Network segmentation (VLANs) Network monitoring Security incident reports Proactive defense
LAB 10 Detection
Intrusion Detection & Prevention Systems (IDS/IPS)
Objective: Students will learn to deploy and configure intrusion detection and prevention systems. By the end of this module, students will be able to install and configure Snort IDS/IPS, create custom Snort rules, install and configure Suricata, use the Elastic Stack (ELK) for security monitoring, analyze IDS/IPS logs, detect and respond to security events, implement Security Information and Event Management (SIEM), and create security incident reports. Students will also understand the difference between IDS and IPS.
Snort IDS/IPS installation and configuration Custom Snort rules Suricata installation and configuration Elastic Stack (ELK) for security monitoring Log analysis Security event detection SIEM implementation Security incident reports
LAB 11 Malware
Malware Analysis & Detection
Objective: Students will learn techniques for analyzing and detecting malware. By the end of this module, students will be able to perform static malware analysis (file hashing, strings analysis, PE headers), perform dynamic malware analysis (sandbox execution, process monitoring), use YARA rules for malware detection, use VirusTotal for hash analysis, analyze malware behavior and Indicators of Compromise (IOCs), create YARA rules for custom detection, use ClamAV for virus scanning, and create malware analysis reports. Students will also understand the importance of malware analysis in incident response.
Static malware analysis (file hashing, strings analysis, PE headers) Dynamic malware analysis (sandbox execution, process monitoring) YARA rules VirusTotal Indicators of Compromise (IOCs) ClamAV Malware analysis reports Incident response
LAB 12 Forensics
Digital Forensics & Incident Response
Objective: Students will learn digital forensics and incident response techniques. By the end of this module, students will be able to create forensic images (dd, FTK Imager), analyze memory dumps using Volatility, analyze disk images using Autopsy, recover deleted files (Foremost, Scalpel), maintain chain of custody, perform incident response (containment, eradication, recovery), analyze security logs, and create forensic investigation reports. Students will also understand the legal considerations of digital forensics.
Forensic imaging (dd, FTK Imager) Memory forensics (Volatility) Disk forensics (Autopsy) File recovery (Foremost, Scalpel) Chain of custody Incident response (containment, eradication, recovery) Log analysis Forensic investigation reports
LAB 13 Capstone
Complete Security Assessment
Objective: Students will apply all the skills learned throughout the course to complete a comprehensive security assessment. By the end of this capstone project, students will be able to plan and execute a complete penetration test, conduct reconnaissance and OSINT, perform vulnerability scanning and exploitation, document all findings and evidence, provide remediation recommendations, create a comprehensive security assessment report, and present findings to stakeholders. Students will also develop project management, teamwork, and communication skills essential for real-world cybersecurity.
Penetration testing planning and execution Reconnaissance and OSINT Vulnerability scanning and exploitation Evidence documentation Remediation recommendations Security assessment reports Presentation and communication Project management and teamwork
